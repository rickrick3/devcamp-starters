# DevCamp Cohort 01 — TaskFlow starter templates

Each `week-XX` folder holds the files a mentee copies into their `taskflow` repo at the start of that week.
Starters give the plumbing; every `TODO` is the mentee's job. Where a pattern is new, one example is done and the rest are `TODO`.

| Folder | Copy into | Branch |
|---|---|---|
| `week-00-hello-devcamp/` | new repo `hello-devcamp` | `main` |
| `week-01-spec/` | `taskflow/` | `week-01-spec` |
| `week-02-static/` | `taskflow/` | `week-02-html-css` |
| `week-03-vanilla-js/` | `taskflow/` (next to the Week 2 files) | `week-03-js` |
| `week-04-react/frontend/` | `taskflow/frontend/` | `week-04-react` |
| `week-05-django/backend/` | `taskflow/backend/` | `week-05-api` |
| `week-06-integration/` | merge into `frontend/` and `backend/` | `week-06-auth` |
| `week-07-tests/` | merge into `frontend/` and `backend/` | `week-07-deploy` |
| `week-08-final/` | `taskflow/README.md` | `week-08-final` |

Also copy `.gitignore` to the root of `taskflow` in Week 1, and post `templates/REFLECTION.md` with every submission.
Each week folder has a short `README.md` with the steps for that week.
